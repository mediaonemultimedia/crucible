Reveal 01

A carved height map sets a per-pixel threshold. The surface reveals once the local dwell field climbing under the cursor passes that pixel's threshold — low ground goes first, high ground resists — so the boundary follows the map's contours, not a circle.

Relief 02

Dwell is accumulated, not instantaneous — it climbs while the cursor lingers near a patch and bleeds off once it leaves. The same field that drives the reveal also pushes a height-map-aligned parallax offset, so lingered ground visibly gains relief the longer you stay.

Method Every pair carries a procedurally carved grayscale height field — layered, domain-warped value noise, not a radial gradient. A low-resolution accumulator texture tracks how long the cursor has lingered over each patch of the surface, charging where it stays and bleeding off where it doesn't. The reveal thresholds each pixel's dwell against that pixel's height; the same dwell field also drives a gradient-aligned parallax offset, so the longer a patch is attended to, the more it reads as carved rather than merely faded.
