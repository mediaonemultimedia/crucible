# Tusche — source (seed)

Seed for a new Crucible piece. **Tusche** is the greasy lithographic ink that painters lay down as fluid, painterly washes on stone.

- `prototype/index.html` is a working real-time WebGL2 watercolour sim: a porous-medium wet layer that carries pigment, darkens at the edges as it dries, settles pigment into a stain layer, and follows paper-fibre absorbency. Click and hold to bloom, drag to stroke, 1/2/3 switch inks (sumi, vermilion, gold), shift-drag lays clear water, D dries, C clears, P plays a scripted demo (or load with `?demo`).
- `reference/` holds an offline mock-up of the target look, painted with p5.brush. It is a style reference only; don't ship it.

Art direction from the owner: off-white paper; Japanese sumi-e brush and watercolour; blacks, reds and golds; lots of watercolour bleed; dwelling longer in one place blooms further.
