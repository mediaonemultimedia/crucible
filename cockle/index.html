Fold 02

Lift height sets how far the hinge rotates before laying the peeled flap back down — low values barely crack the sheet open, high values fold it almost flat behind itself. Pull distance is a separate outward drift on top of that, independent of the rotation.

Cockle 03

Buckle facets are seeded once per panel and masked to the active fold line — the sheet stays crisp at rest and only shows its imperfections where it's currently under bending stress.

Layers 04

Top layer

The panels overlap at rest instead of butting edge to edge — the top layer is which one sits above at that seam. On open, the bottom layer waits for delay before it starts peeling, so the stack un-layers instead of both sheets lifting as one.
