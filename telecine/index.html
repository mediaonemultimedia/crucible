Scene 01

Three hand-authored keyframe files, each a small JSON document — the same shape a real After Effects export would carry: position, scale, rotation and opacity per layer, sampled over time.

Timeline 02

Drag the scrubber, use ← →, or scroll over the stage — every position calls the same sample(t) function the render loop uses. Nothing here is a video frame; every value on screen is interpolated fresh from the JSON for the exact time requested.

Schema 03

Each layer keyframe is { time, value, easing }. Easing is either "linear" or a cubic bézier { x1,y1,x2,y2 } — the same handle-pair shape AE stores per keyframe. This is a deliberate Phase 1 stand-in for a real AE export, not a parser for actual .aep project data. See the PR description for exact scope.

Scene —
Method No frame of this animation is baked. A JSON file lists each layer's position, scale, rotation, opacity as keyframes — plain numbers at plain times — and the engine asks, for whatever instant you land on, "what does every property equal right now?" by interpolating between the two surrounding keyframes with that keyframe's easing curve. Scrub anywhere; it renders that instant directly, not the nearest frame.
